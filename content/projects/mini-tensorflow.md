mini-TensorFlow implements multidimensional tensors, broadcasting, matrix
operations, sequential models, dense and convolutional layers, activation
functions, optimizers, data loading, and model serialization.

It is designed as a compact learning environment for understanding how the
pieces of a deep-learning library connect. SIMD and parallel execution paths
make the performance layer visible without turning the project into a claim of
feature parity with mature production frameworks.
